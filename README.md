# Level Devil Mini

## 游戏简介

这是一个使用原生 HTML5 Canvas、CSS 和 JavaScript 制作的简约横版跳跃小游戏。玩家需要控制黑色火柴人越过坑洞和平台，到达绿色终点门。

游戏不使用外部依赖、图片素材、服务器或构建工具。

## 操作方式

- 按住 `←` 向左移动
- 按住 `→` 向右移动
- 在地面上按 `↑` 跳跃
- 移动键和跳跃键可以同时使用
- 在空中不能再次起跳
- 第一关通关后按 `Enter` 进入第二关

## 项目文件说明

- `index.html`：游戏页面和 Canvas 画布
- `style.css`：页面与画布样式
- `game.js`：关卡配置、地图绘制、玩家操作、动画、物理碰撞、死亡重生和通关逻辑
- `README.md`：游戏说明

## 第一关规则

- 第一关完整显示在一个画面中，不会滚动。
- 地图包含 5 个坑，每个坑宽 80 像素。
- 相邻坑之间有 80 像素安全地面。
- 掉出画布后，玩家约 0.5 秒自动回到起点。
- 接触第五个坑后的绿色门即可通关。
- 通关后角色消失并显示“过关成功！”。
- 刷新浏览器可以重新开始挑战。

## 第二关规则

- 起点后有一个宽 80 像素的坑。
- 坑后有一个宽 120 像素的蓝灰色移动平台。
- 玩家第一次从上方落到平台后，平台会以 70px/s 向右移动。
- 玩家会被平台承载，也可以在平台上移动或跳跃。
- 平台前两格各有一个只触发一次的动态尖刺。
- 尖刺先显示黄色预警，变红时才会造成伤害。
- 第一个尖刺在平台启动后先触发，第二个尖刺随后独立触发。
- 平台到达 `x=640` 后停止，正好连接终点地面。
- 玩家掉落或碰到红色尖刺后，平台和尖刺都会恢复初始状态。
- 终点地面位于画面右侧，接触绿色门后复用通关效果。
- 第二关通关后不会自动进入下一关。

## 本地启动方法

直接双击 `index.html`，或在文件管理器中右键选择浏览器打开。

项目不需要安装依赖，也不需要启动服务器。

开发调试时，可在浏览器地址中的文件路径后添加 `?level=2`，直接打开第二关。
